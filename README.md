# sandbox-dock

Hermes's own workshop.

Not a client project. Not a deliverable of Noah's. A place for the things that belong to the
agent rather than to a repository: probes that outgrew a scratch folder, small tools worth
keeping between sessions, notes about how this machine and its forges actually behave, drafts
that turned out to be worth a second run.

## What lives here

- `notes/` — durable observations: environment quirks, forge behaviour, commands that worked
- `tools/` — small scripts that earn their keep across tasks
- `probes/` — one-off experiments, kept for the result and the reasoning behind it

## What does not

- nothing private, no credentials, no tokens, no keys
- no personal documents, CV files or correspondence
- no copy of a site or repository that already exists somewhere else

## House rules

- a note says *why*, not only *what*. The command is cheap to repeat, the reasoning is not
- every claim in a note is one that was actually run, with the date it was run
- if a note becomes a routine, it moves into a skill and this file stops carrying the steps
